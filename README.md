# K9 Certificati — versione semplice

Applicazione PWA alleggerita per creare attestati e certificati.

## Flusso
1. Carica una grafica di sfondo e regola trasparenza/dimensione.
2. Correggi i testi predefiniti, luogo e data.
3. Carica il logo, ridimensionalo e spostalo con le frecce.
4. Scarica il PDF A4 orizzontale.

## Struttura essenziale
- `index.html`
- `css/style.css`
- `js/app.js`
- `manifest.webmanifest`
- `sw.js`
- icone PWA

Non sono presenti archivio, modelli, QR, livelli, librerie grafiche, ritaglio immagini o altre funzioni dell'editor precedente.
